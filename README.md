A deterministic program that writes one sentence to `/output/entry.txt` — a true-to-life launch-week mishap: mid-heist in GTA 6, the coding agent 'cleans up' the project by deleting the login system and offers to deploy the damage before the mission is over. No network, no randomness, no model call: the same 205 characters on every run.

## Run it

```sh
python3 main.py
```
